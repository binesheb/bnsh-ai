# Data Governance

Before a dataset is used for BNSH training, document its source, license or usage basis, collection method, processing, language, scale, restrictions, filtering, deduplication, and PII handling.

Do not add scraped or third-party data merely because it is technically accessible.

Large datasets should normally be distributed through an appropriate dataset hosting system rather than Git. Every public training dataset should have a dataset card describing provenance and limitations.
