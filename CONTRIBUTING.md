# Contributing to BNSH AI

BNSH AI is intended to become an open model project. Contributions are welcome across software, datasets, evaluation, documentation, infrastructure, and model research.

## Before contributing

- Check existing issues and pull requests.
- Keep changes focused and reviewable.
- Do not add data whose license or provenance is unclear.
- Do not commit model weights or large generated artifacts to the source repository.
- Add tests for behavior that can be tested automatically.
- Document meaningful architectural decisions.

## Areas of contribution

- Runtime and inference
- Training infrastructure
- Dataset processing
- Multilingual evaluation
- Model evaluation
- Developer SDKs
- Documentation
- BINESH OS integration

## Pull requests

Describe what changed, why it changed, how it was tested, and any compatibility implications.
